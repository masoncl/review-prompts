# Questions: Race Condition Tracing

- guide: races.md
- title: Race Condition Tracing
- verbatim: ../verbatim/races.md

The race-tracing method is not something a kernel tree can answer, so it has no
questions. `kernel/subsystem/verbatim/races.md` is maintained by hand and a
build copies it into the build directory as it is, so that the build directory
holds every guide a review can load. It was split out of the hand-written
locking guide, whose reference half is built from `locking.md` here.
